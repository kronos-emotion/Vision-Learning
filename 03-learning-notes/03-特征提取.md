# 特征提取与模板匹配

> 从图像中提取有意义的特征，用于定位、识别和检测。

## 1. 轮廓分析

轮廓是图像中连通区域的边界点集，是最常用的特征。

### 轮廓查找
```python
contours, hierarchy = cv2.findContours(
    binary_img, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
```

### 常用轮廓特征

| 特征 | 函数 | 说明 |
|------|------|------|
| 面积 | `cv2.contourArea(c)` | 轮廓内像素数 |
| 周长 | `cv2.arcLength(c, True)` | 轮廓总长度 |
| 外接矩形 | `cv2.boundingRect(c)` | 轴对齐矩形 (x,y,w,h) |
| 最小外接矩形 | `cv2.minAreaRect(c)` | 旋转矩形 |
| 最小外接圆 | `cv2.minEnclosingCircle(c)` | 圆心和半径 |
| 多边拟合 | `cv2.approxPolyDP(c, eps, True)` | 用较少顶点近似轮廓 |

### 轮廓筛选的典型流程
```python
for c in contours:
    area = cv2.contourArea(c)
    if area < 100 or area > 10000:
        continue  # 过滤面积过大或过小
    x, y, w, h = cv2.boundingRect(c)
    aspect = w / h
    if aspect < 0.5 or aspect > 2.0:
        continue  # 过滤长宽比不符合的
    # 剩下的就是候选目标
```

## 2. 模板匹配

在图像中寻找与模板最相似的区域。

### 基本原理
将模板图像在目标图像上滑动，每次计算相似度，取最大值位置。

```python
result = cv2.matchTemplate(image, template, method)
min_val, max_val, min_loc, max_loc = cv2.minMaxLoc(result)
```

### 匹配方法

| 方法 | 公式 | 特点 |
|------|------|------|
| TM_CCOEFF_NORMED | 归一化相关系数 | **最推荐**，对光照变化鲁棒 |
| TM_CCORR_NORMED | 归一化互相关 | 速度快，但对光照敏感 |
| TM_SQDIFF_NORMED | 归一化平方差 | 值越小越匹配 |

### 局限性
- **不抗旋转**：模板旋转后匹配率急剧下降
- **不抗缩放**：目标大小变化需要多尺度匹配
- **不抗遮挡**：部分遮挡可能导致匹配失败

## 3. 角点检测

角点是图像中梯度在两个方向都变化明显的点。

### Harris 角点检测
```python
corners = cv2.cornerHarris(gray, blockSize=2, ksize=3, k=0.04)
```

### Shi-Tomasi 角点检测（更常用）
```python
corners = cv2.goodFeaturesToTrack(gray, maxCorners=100,
                                   qualityLevel=0.01, minDistance=10)
```

## 4. Blob 分析

检测图像中的斑点（连通区域），适合定位特定形状。

```python
params = cv2.SimpleBlobDetector_Params()
params.filterByArea = True
params.minArea = 100
params.filterByCircularity = True
params.minCircularity = 0.7

detector = cv2.SimpleBlobDetector_create(params)
keypoints = detector.detect(gray)
```

## 5. 工业视觉中的典型应用

### 定位（找位置）
```
模板匹配 / 轮廓匹配 → 获取物体中心坐标和旋转角度
→ 传递给机械臂或运动平台
```

### 测量（量尺寸）
```
边缘检测 → 边缘拟合直线/圆
→ 计算距离/直径/角度
```

### 识别（判类别）
```
提取特征（面积、周长、圆形度等）
→ 设定阈值或训练分类器判断OK/NG
```
