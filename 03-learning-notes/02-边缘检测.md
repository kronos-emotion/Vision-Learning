# 边缘检测

> 边缘是图像中像素值发生剧烈变化的位置，是视觉测量的基础。

## 1. 边缘的类型

- **阶跃边缘**：亮度从一个值跳到另一个值（物体边界）
- **屋顶边缘**：亮度先升后降（细线）
- **斜坡边缘**：亮度逐渐变化（模糊边界）

## 2. Sobel 算子

一阶导数的离散近似，计算图像梯度。

```
Gx = [-1 0 +1; -2 0 +2; -1 0 +1]   ← 水平梯度
Gy = [-1 -2 -1; 0 0 0; +1 +2 +1]   ← 垂直梯度
```

- 梯度幅值：`G = sqrt(Gx² + Gy²)`
- 梯度方向：`θ = atan2(Gy, Gx)`

```python
# 计算 x 和 y 方向的梯度
grad_x = cv2.Sobel(img, cv2.CV_64F, 1, 0, ksize=3)
grad_y = cv2.Sobel(img, cv2.CV_64F, 0, 1, ksize=3)
# 计算梯度幅值
magnitude = cv2.magnitude(grad_x, grad_y)
```

## 3. Canny 边缘检测 ✅ (工业中最常用)

**Canny 是最推荐的边缘检测算法**，因为它满足三个标准：
1. **低错误率**：尽可能少地漏检和误检
2. **精确定位**：检测到的边缘尽可能接近真实边缘
3. **单响应**：每个边缘只检测一次

### Canny 算法步骤

```
输入图像 → 高斯滤波 → 计算梯度幅值和方向
    → 非极大值抑制 → 双阈值检测 → 输出边缘
```

### 关键参数：双阈值

```python
edges = cv2.Canny(img, threshold1, threshold2)
```

- `threshold1`（低阈值）：低于此值的不是边缘
- `threshold2`（高阈值）：高于此值的确定为强边缘
- 介于两者之间：仅当与强边缘相连时才作为边缘

**调参原则：**
- 光照好、对比度高：`Canny(img, 50, 150)`
- 光照差、噪声多：`Canny(img, 30, 90)` 或先加大滤波
- 经验法：`threshold2 ≈ 3 × threshold1`

### Canny vs Sobel

| 特性 | Sobel | Canny |
|------|-------|-------|
| 输出 | 梯度幅值图像 | 二值边缘图 |
| 边缘连续性 | 可能断裂 | 较好（双阈值连接） |
| 参数 | 1个（核大小） | 2个（高低阈值） |
| 工业应用 | 少 | **极多** |

## 4. 边缘检测后的处理

Canny 输出的边缘图通常还需要：
1. **形态学操作**：闭运算连接断裂边缘
2. **轮廓查找**：`cv2.findContours()`
3. **轮廓筛选**：按面积、长宽比、圆形度过滤

## 5. 实践建议

```python
# 工业视觉中推荐的边缘检测流水线
def detect_edges(gray):
    # 1. 高斯滤波
    blurred = cv2.GaussianBlur(gray, (5, 5), 0)
    # 2. CLAHE 增强
    clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
    enhanced = clahe.apply(blurred)
    # 3. Canny 边缘检测
    edges = cv2.Canny(enhanced, 50, 150)
    # 4. 闭运算连接边缘
    kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))
    closed = cv2.morphologyEx(edges, cv2.MORPH_CLOSE, kernel)
    return closed
```
