# 图像预处理

> 预处理是视觉检测的第一步，决定了后续算法的上限。

## 1. 灰度化

相机采集的彩色图像数据量大，且颜色信息在很多检测场景中并非必要。灰度化将三通道压缩为单通道，降低计算量。

**常用方法：**
- 加权平均法：`Gray = 0.299R + 0.587G + 0.114B`（OpenCV默认）
- 平均值法：`(R+G+B)/3`

## 2. 图像滤波

滤波的目的：**去噪**，同时尽可能保留边缘信息。

### 高斯滤波
```
K = (1/16) × [1 2 1; 2 4 2; 1 2 1]
```
- 核内像素按高斯分布加权平均
- 对高斯噪声效果最好
- `cv2.GaussianBlur(img, (5,5), 0)`

### 中值滤波
- 核内像素取中位数
- 对椒盐噪声（黑白点噪声）效果最好
- 边缘保留能力优于高斯滤波
- `cv2.medianBlur(img, 5)`

### 双边滤波
- 同时考虑空间距离和像素值差异
- 去噪同时保留边缘
- 计算量大，实时性差
- `cv2.bilateralFilter(img, 9, 75, 75)`

## 3. 直方图均衡化

增强对比度的核心技术。

### 全局直方图均衡化
- 将灰度分布拉伸到整个0-255范围
- 缺点：噪声同时被放大

### CLAHE (自适应直方图均衡化)
```
clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8,8))
enhanced = clahe.apply(gray)
```
- 将图像分块，每块独立做均衡化
- `clipLimit` 限制对比度放大倍数，避免噪声过度放大
- 对光照不均场景效果显著

## 4. 形态学操作

### 腐蚀 (Erosion)
- 核内全为白色时保留，否则变为黑色
- 效果：白色区域缩小，消除小亮点

### 膨胀 (Dilation)
- 核内有一个白色就变为白色
- 效果：白色区域扩大，填充小孔

### 开运算 (Opening) = 腐蚀→膨胀
- 消除细小白色噪点，断开物体间的细连接
- `cv2.morphologyEx(img, cv2.MORPH_OPEN, kernel)`

### 闭运算 (Closing) = 膨胀→腐蚀
- 填充物体内部小孔，连接断裂的轮廓
- `cv2.morphologyEx(img, cv2.MORPH_CLOSE, kernel)`

**工业视觉中的典型用法：**
```
1. 高斯滤波去噪
2. 阈值分割提取目标区域
3. 闭运算填充目标内部孔洞
4. 开运算去除背景噪点
5. 轮廓分析提取目标特征
```
