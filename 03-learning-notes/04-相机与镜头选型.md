# 相机与镜头选型

> 视觉系统的"眼睛"，选型直接影响检测精度和稳定性。

## 1. 工业相机分类

| 类型 | 传感器 | 特点 | 适用场景 |
|------|--------|------|---------|
| **CCD** | 电荷耦合器件 | 图像质量高、噪声低、成本高 | 高精度检测 |
| **CMOS** | 互补金属氧化物 | 速度快、成本低、消费级主流 | 高速检测、一般精度 |

### 关键参数

**分辨率**：宽×高（像素）
- 常见：500万（2592×1944）、1200万、2000万
- 选型公式：`视野(mm) / 精度(mm) = 所需像素数`

**帧率 (FPS)**：每秒采集帧数
- 静态检测：15-30 FPS 足够
- 流水线高速检测：需要 60-200+ FPS

**像元尺寸**：单个像素的物理尺寸（μm）
- 越大 → 感光越好 → 弱光表现好
- 越小 → 分辨率越高 → 但噪声增加

**靶面尺寸**：传感器对角线长度（英寸）
- 常见：1/3"、1/2"、2/3"、1"
- 靶面越大 → 视野越大 → 镜头越贵

## 2. 镜头参数

### 焦距 (f)
- 影响：视角大小（焦距越短，视野越大）
- 选型：`焦距 = 工作距离 × 靶面尺寸 / 视野`

### 光圈 (F)
- F 值越小，进光量越大
- 小光圈 → 景深大（清晰范围大）→ 但进光少
- 大光圈 → 景深小 → 边缘可能模糊

### 景深 (DOF)
- 物体前后清晰的范围
- 影响因素：光圈小→景深大，焦距短→景深大，工作距离远→景深大

### 畸变
- 镜头固有的光学失真
- 广角镜头畸变大，长焦镜头畸变小
- 高精度测量需要**远心镜头**

## 3. 镜头类型

| 类型 | 特点 | 适用场景 |
|------|------|---------|
| **定焦镜头** | 固定焦距，图像质量好 | 视野固定的场景 |
| **变焦镜头** | 可调焦距，灵活 | 需要调整视野 |
| **远心镜头** | 无透视畸变，放大倍率恒定 | **高精度测量** |
| **显微镜头** | 极高放大倍率 | 微米级检测 |

## 4. 选型流程

```
1. 确定检测精度要求
   └─ 例：检测 ±0.1mm 的特征 → 精度需 0.05mm/pixel
   
2. 确定视野大小 (FOV)
   └─ 例：检测 50mm × 40mm 区域

3. 计算所需分辨率
   └─ 宽：50 / 0.05 = 1000 pixel
   └─ 高：40 / 0.05 = 800 pixel
   └─ 选：1280 × 1024（留余量）

4. 确定工作距离 (WD)
   └─ 例：镜头到物体 200mm

5. 计算焦距
   └─ 焦距 = 200 × 靶面高 / 40
```

## 5. 新手建议

- **起步阶段**：先用手头的 USB 相机或手机摄像头学习，理解图像处理
- **第一台工业相机**：推荐 500万像素 CMOS + 12mm或16mm定焦镜头
- **测量项目必用远心镜头**：普通镜头有透视畸变，不适合高精度测量
