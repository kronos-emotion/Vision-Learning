# 光源选型

> 在机器视觉中，**打光比算法更重要**——好的打光让检测变得简单。

## 核心原则

光源的目的是在目标特征和背景之间**创造最大的对比度**。

## 1. 常见光源类型

| 类型 | 形状 | 特点 | 适用场景 |
|------|------|------|---------|
| **环形光源** | 环形，中间镂空 | 安装方便，均匀性好 | 字符识别、外观检测 |
| **条形光源** | 长条形 | 可组合，角度灵活 | 大面积打光、划痕检测 |
| **背光源** | 平面发光 | 轮廓清晰，反差极大 | **尺寸测量**、边缘检测 |
| **同轴光源** | 垂直出光 | 消除反光 | 镜面物体、高反光表面 |
| **点光源** | 点状 | 高亮度，小区域 | 定位、补光 |
| **穹顶光源** | 半球形 | 漫射，无阴影 | 弧形表面、易反光物体 |

## 2. 打光方式

### 明场照明
- 光线从正面照射，相机接收反射光
- 背景亮，物体暗
- 适用：大多数常规场景

### 暗场照明
- 光线以低角度照射，相机接收散射光
- 背景暗，缺陷亮（如划痕会发光）
- 适用：**划痕检测、凹凸检测**

### 背光照明
- 光源在物体后方，相机看轮廓
- 物体为黑色剪影，背景亮
- 适用：**尺寸测量、边缘检测、外形检测**

```
      相机                   相机                   相机
        |                     |                     |
        |                     |                     |
    ────┘└──── 光源      ────┘└────          物体  │
        |                     |                 ───┘└───
        |                     |                 ───┐┌───
      ──物体──            物体  │               光源 │
        |                     |                     |
      ──┘└─── 背景        ──┘└─── 背景
    -----------            -----------           -----------
    明场照明                 暗场照明              背光照明
```

## 3. 不同材质的光源策略

| 物体材质 | 推荐光源 | 原因 |
|---------|---------|------|
| 金属（反光） | 同轴光源或穹顶光源 | 消除反光 |
| 塑料 | 环形光源 | 均匀照亮表面 |
| 玻璃/透明 | 背光源 | 清晰显示轮廓和缺陷 |
| PCB电路板 | 环形光源 + 条形光源 | 突出焊点和导线 |
| 橡胶/黑色物体 | 高角度环形光 | 增加对比度 |
| 曲面物体 | 穹顶光源 | 避免局部过曝 |

## 4. 光源颜色选择

**基本原则：互补色增强对比度**

- 红色光 → 蓝色/绿色物体上更亮
- 蓝色光 → 红色/黄色物体上更亮
- 白色光 → 通用

**为什么用单色光？**
- 彩色相机的 Bayer 滤镜会损失 50%+ 的感光度
- 单色光 + 黑白相机 = 更高对比度 + 更好信噪比

## 5. 新手建议

- **起步**：先用普通台灯练习打光，找到最佳角度
- **必备光源**：环形光源（通用性最强）+ 背光源（测量用）
- **调试步骤**：
  1. 先确定物体材质（反光/吸光/透明）
  2. 再选择光源类型
  3. 调整光源角度和高度，观察对比度变化
  4. 固定最佳方案
